# Rule: coexistence and tiers

Applies to sandbox, neighbors, legacy lane, adapters.

- Ladder: cooperate -> yield -> self-disable -> refuse
- Force-enable cannot outrank REFUSE
- Unknown mods default safe (legacy), never silent parallel
- Neighbor postures prefer data (weft-neighbors.toml)
- Tier upgrades need evidence; adapters are the structural path for Create/AE2-class systems (P3)
